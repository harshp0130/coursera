
1. Purpose
This Code of Conduct aims to ensure a positive, inclusive, and respectful environment for all contributors and participants in this project.

2. Our Standards
To foster a welcoming and inclusive community, we commit to:

Using respectful and inclusive language.
Being kind and considerate to others.
Welcoming constructive feedback and collaboration.
Avoiding personal attacks, harassment, or discrimination.
Respecting differing viewpoints and experiences.
Unacceptable behavior includes:

Harassment, discrimination, or hate speech of any kind.
Publishing private information without consent.
Trolling, insults, or other disruptive behavior.
3. Enforcement Responsibilities
Project maintainers have the authority to enforce this Code of Conduct and take appropriate action, including warnings or removal from the project, if necessary.

4. Reporting Violations
If you experience or witness any violations of this Code of Conduct, please report them by contacting [your email or GitHub contact]. All reports will be handled confidentially.

5. Acknowledgment
By participating in this project, you agree to abide by this Code of Conduct.

6. Attribution
This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
